## 1. 竞品格局

**免费的一侧**
- **Apple Continuity Camera** —— macOS 自带，iPhone 变无线摄像头，零成本。**这一块你的价值主张直接归零。**
- Camo 有受限免费版

**收费的一侧**
- Camo：$8.99/月 · $49.99/年 · $99.99/终身
- EpocCam：$7.99 一次性（只做摄像头这一件事）

**你多出来的部分**（Camo、EpocCam、Apple 都没有）
- 触控板、键盘、语音听写
- 应用窗口镜像
- **通知中继 + 点一下回到那个窗口**
- **18 套情景模式**（49 个 app 映射）
- 扩展显示器（手机当副屏）

**结论：这个品类的付费成立**（Camo 靠它卖了十年），**但付费理由不是摄像头**。摄像头是免费锚点，付费买的是"摄像头之外的那一半"。

## 2. 在哪卖

你的 Mac 端是 Developer ID 分发，**不在 Mac App Store**。这给了两条不同的路：

| 渠道 | 费率 | 适合 | 麻烦 |
|---|---|---|---|
| **App Store 非消耗型 IAP** | **15%**（小企业计划） | iOS 用户 | 只能 iOS 用 |
| **Lemon Squeezy** | **5% + $0.50** | Mac 用户 | 需要自己做授权校验 |
| Paddle | 5% + $0.50（SAAS）/ 8%（数字商品） | 备选 | 同上 |
| Gumroad | ~13% + $0.30 | 不推荐 | 费率最高，但有 146K 商品的流量池 |

**建议架构**
- **iOS → App Store 非消耗型 IAP**（$59 / $99 两档）。用户信任 Apple 支付，不需要你处理税。
- **Mac → Lemon Squeezy**。5% + $0.50，自动处理全球 VAT（德国/法国/日本的数字服务税各不相同），**内置 license key 管理**（可停用、可重发），135+ 国家支付方式。

**到手金额对比（$99 终身）**

| 渠道 | 抽成 | 你拿到 |
|---|---|---|
| App Store（小企业计划） | 15% | **$84.15** |
| Lemon Squeezy | 5% + $0.50 | **$93.55** |

小企业计划条件：上年 App Store 收入 < $100 万。**符合，但要主动申请**，不申请就是 30%。

⚠️ **一个正在变动的变量**：Apple 2026-08-14 向法院提交方案，拟对 App 内跳转外链收 15%（小企业计划 5%）。**这是提案，仍在 Epic 诉讼中，不是现行规则。** 不要基于它做规划。iOS 侧老老实实用 IAP。

## 3. 权益设计（最核心的决策）

### 3.1 免费档 —— 建议永久完整

Camo 的模型是"受限免费 + 付费 Pro"，你抄这个结构。但**受限的方式要不一样**。

**建议：按"规模"收费，不按"功能"收费。**

| 免费（永久，不可变） | Pro（一次性买断） |
|---|---|
| 摄像头、麦克风 | **多设备**：1 台手机 → 多台 Mac；多台手机 → 1 台 Mac |
| 触控板、键盘、语音 | **4K / 高码率**（免费档是 1080p） |
| 窗口镜像 | **扩展显示器**（手机当 macOS 副屏） |
| 通知中继 | **录制工作室**（拍摄/录音/窗口，带时间轴） |
| 18 套情景模式 | **Windows 接收端** |
| **1 台设备** | 优先支持 |

**为什么这么切**
1. 一个人用一台 Mac 一台手机 —— **这是绝大多数人的场景，全部免费**。免费档是真的完整，不是试玩版。
2. 收费买的是"多台"和"更强"，不是"能不能用"。**没有一个免费用户的核心场景被拿走了。**
3. 这让"免费转收费"在道德上站得住：收费的是**规模**，不是**访问权**。

**⚠️ 扩展显示器的特殊风险**：它现在跑在未公开的 macOS 私有 API 上（课 70 写明：macOS 更新可能随时打断）。**不要放进 Pro 的核心承诺。** 建议措辞：Pro 买的是"这个功能存在过，且我们持续修"，不是"保证永远能用"。FAQ 里公开写"实验性功能，依赖未公开 API"。

### 3.2 "免费只是临时的"怎么处理

你原话是"我现在的免费只是临时的，以后肯定要收费"。**这句话本身没问题，问题的是它不能是事后才说。**

现在起做三件事，一件都不能少：

1. **官网现在就挂定价表**。不是"未来可能收费"，是明确的表格。
2. **现在就开始收集注册**。钩子是"提前注册 → Pro 免费用 12 个月"。这同时是你的名单来源。
3. **Pro 上线时给至少 6 个月缓冲。** 今天（9 月）开始收注册，Pro 最早 2027 Q1，那就是 6 个月以上。

**反过来，"临时免费"是可能的，不是必然的。** 如果 Pro 的功能确实有价值（上面 3.1 那个切法），你可以永远保持免费档完整，只在 Pro 上收。

## 4. 众筹：诚实评估

你的问题：**不做实物，上线后还能不能众筹？**

### 4.1 政策原文（硬约束）

Kickstarter 条款：

> "backers agree and acknowledge they're not buying something when they back a project — they're **helping to create something new, not ordering something that already exists**."

App 类项目规则：必须展示 prototype。

**你的主体产品已免费、公开、可下载。** 拿它去众筹，评审有理由拒，backer 有理由质问。

### 4.2 但有真成功的纯软件先例

| 案例 | 金额 | backer | 结构 |
|---|---|---|---|
| **Font Awesome 5** | $1,076,960 | 35,550 | $20 早鸟 Pro · $40 加一授权 · $150 十张授权。FAQ 明确写"永久授权，无续费" |
| **Fluent Forever** | $587,785 | 4,434 | $40 入场（beta），主力在高档位。语言包 app 内加装 ~$25 |
| **Seedtime** | $341,796 | 2,212 | $199 = 33% off 明示零售价 $295 |
| **Guildstew**（2026-09-30 上线） | 目标 $10,000 | — | $5 数字档（beta+徽章+**数字壁纸包**）→ $15 → $25（首次含实物：贴纸书签）→ $50 → $150 → $250 |

**Guildstew 的 $5 档"数字壁纸包"就是"不做实物"的解法**：原创美术、专属图标、限定主题 —— backer 拿得到、看得见，但你不用发快递、不用做库存。

### 4.3 为什么 Font Awesome 那个数字不能当参照

它有 35,550 个 backer。那不是众筹做出来的，是**十几年积累的邮件列表**。你现在的流量来源：App Store（刚过审）、网站、YouTube 3 条片子。

**$25,000 目标 / $59 均价 = 需要约 425 个 backer。按 5–8% 转化率，需要 5,000–8,000 的 pre-launch 名单。你大概只有需求量的 1/5。**

### 4.4 建议

**不要为 Pro 的发布做众筹。** 你要筹的东西是免费的，而且目标人群（Mac mini 用户、开发者）不在 Kickstarter 的核心浏览行为里（那是硬件和设计品类）。

**如果一定要筹，筹一个真正还没做的东西**，而且是在 Pro 收钱跑一段时间、有了名单之后：
- **Android 客户端**（路线图里真有的）—— 这是"另一个产品"
- **Agent 路由系统**（通知中继 + 点一下回到窗口，agent 侧那半边）—— 有故事、有独家性、面向开发者

**现有 KS 草稿建议保留但不上线**（草稿免费、不可见），它是一份写得不错的可复用文案。
