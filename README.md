# RemoteCrab

Turn an iPhone / iPad into a WiFi-attached camera, microphone, trackpad
and keyboard for Mac / Windows. Built around Apple's **Liquid Glass**
design language (iOS 26 / macOS Tahoe+).

## Architecture (V0.1)

```
┌────────────────────┐                  ┌────────────────────┐
│   iOS (iPhone)     │                  │   Mac              │
│  RemoteCrabCapture    │                  │  RemoteCrabReceiver   │
│                    │                  │                    │
│  AVCaptureSession   │   Bonjour (TCP) │  NWBrowser          │
│        │            │ ───────────────► │        │            │
│        ▼            │   "_remotecrab"    │        ▼            │
│  VTCompressionSession│  length-prefixed│  VTDecompressionSession│
│  (H.264 HW encode) │   NAL units     │  (H.264 HW decode) │
│                    │                  │        │            │
│                    │                  │        ▼            │
│                    │                  │  SwiftUI preview    │
│                    │                  │  window             │
└────────────────────┘                  └────────────────────┘
```

**Wire format** (TCP, length-prefixed):

```
┌─────────────────────────────────────────────────────┐
│  [4-byte BE length][H.264 NAL unit, Annex-B]        │  ← video frames
│  [4-byte BE length][UTF-8 JSON]                     │  ← metadata (SPS/PPS, resolution)
└─────────────────────────────────────────────────────┘
```

## Building

Requirements:
- Xcode 26.0+
- iOS 26.0+ device (iPhone 13 / iPad with A14 or later recommended)
- macOS 26.0+ host

```sh
brew install xcodegen
xcodegen generate --spec project-ios.yml
xcodegen generate --spec project-mac.yml
open RemoteCrabCapture.xcodeproj
open RemoteCrabReceiver.xcodeproj
```

The two projects share `RemoteCrabCore/` via local Swift package reference.

## Design language

Apple Native + Liquid Glass. See `prototypes/02-apple-native.html` for the
chosen visual direction. Design tokens live in `RemoteCrabCore/DesignSystem/`.

## Privacy & App Store

V0.1 is intended for personal / TestFlight distribution. App Store
compliance checklist is in `prototypes/README.md`.

Required Info.plist keys (already set by `project-ios.yml`):
- `NSCameraUsageDescription` — "RemoteCrab turns your iPhone into a WiFi camera for your Mac."
- `NSMicrophoneUsageDescription` — "RemoteCrab streams your iPhone microphone to your Mac."
- `NSLocalNetworkUsageDescription` — "RemoteCrab discovers your Mac on the local network."
- `UIBackgroundModes` — `audio` (added in a later milestone for background streaming)
