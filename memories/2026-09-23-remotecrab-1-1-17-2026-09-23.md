# RemoteCrab 1.1：情境套件 17 类 + 玻璃命中区 + 发版要点（2026-09-23）

# 结论

## 玻璃按钮命中区（通用坑）
自定义 `ButtonStyle` 的命中测试走 **label 的内容形状**，不是外层 Button 的 bounds。
`IBMaterial.glass/bar` 的背景是 `shape.fill(.clear).glassEffect(...)`——透明填充不参与命中，
所以"只有图标/文字可点、卡片右半边是死的"。
**修法：在 ButtonStyle 内部给 `configuration.label` 加 `.contentShape(Rectangle())`**
（`IBPressButtonStyle` + `GlassPressButtonStyle` 已加），不要在单个按钮上补救。

## 情境套件（17 类）
`presentation, agent, finder, notes, browser, mail, messages, calendar, xcode,
editor, text, media, chat, meeting, image, notebook, console`
- `⌘B` 是 App 相关的：Xcode=构建、TextEdit=加粗、VSCode=**切换侧边栏** → 必须拆成
  三套（xcode/editor/text）。
- 网格两列，**每套件动作数必须为偶数**（有测试），同族动作必须相邻同行。
- profile 是 `Codable` + 自描述 `bundleIDs`，为将来"插件市场"预留。

## 校验快捷键的方法（重要）
用 AppleScript 读 App 真实菜单栏：
```
tell application "System Events" to tell process "<App>"
  repeat with m in (every menu bar item of menu bar 1)
    repeat with i in (every menu item of menu 1 of m)
      AXMenuItemCmdChar / AXMenuItemCmdModifiers  (0=⌘ 1=⇧ 2=⌥ 4=⌃ 8=无修饰)
```
据此抓到三处错误绑定：邮件删除=⌘⌫、信息发送=⌘⏎、备忘录删除（裸 ⌫）→ 改 ⇧⌘N 新建文件夹。
Electron（VSCode/Discord/飞书/微信）AX 读不到菜单，用官方文档键位。
