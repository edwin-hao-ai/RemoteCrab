# iBridge UI/发布就绪 经验与踩坑（2026-09-13）

# iBridge 本会话 UI/性能/发布就绪

## UI 踩坑
- **iOS 顶栏是浮层**：ContentView 覆盖一个紧凑顶栏（状态小图标 + `⋯` 溢出菜单）和一个居中 alert 卡片。
  任何 surface（尤其 KeyboardScreen）顶部必须留白（现加 56pt），否则标题被压。
- **状态不要塞进胶囊**：长句在窄胶囊里会**逐字竖排**。连接状态改成居中 alert 卡片（图标+标题+副标题+scrim）；
  顶栏只留小图标。`IBStatusPill` 加了 `lineLimit(1)+minimumScaleFactor`，且 `.disconnected` 不再渲染 reason
  （之前出现"离线 Connection lost"中英混排）。
- **FeatureDock 变高要同步 clearance**：dock 现在 ~118pt（44 PTT 胶囊 + 10 + 64 按钮行）+ 16 padding = 顶部 134pt。
  `TouchpadScreen.dockClearance` 必须是 ~148，否则 ⌃⌥⌘⇧ 修饰键栏会压住"按住说话"。改 dock 记得同步。
- **`MenuBarExtra(.window)` 内容高度一变就重排/动画**：离线行文案换行导致高度变化 → popover 每次重连状态变化都滑动一次，
  看起来像"循环侧向动画"。修法：popover 行**固定高度 + lineLimit(1)**。
- **绝不要把原始 `NWError` 显示到 UI**：会露出 `POSIXErrorCode(rawValue: 54): Connection reset by peer`。
  日志记原始错误，界面显示人话（`IBLocale.Error.iPhoneConnectionLost`）。

## 性能
- **别用常驻 `TimelineView` 做空闲动画**：触控板光标预览 20Hz 永远重绘，切 surface / 开摄像头 PiP 时卡顿。
  改成 `TimelineView(.animation(minimumInterval: 0.05, paused: trail.isEmpty && !isPressed))`。

## 菜单栏图标
- 想用自家 logo：**必须用 monochrome、透明背景、`template-rendering-intent: template` 的 image set**，
  用 `Image("MenuBarIcon").renderingMode(.template)`。母版 `assets/menu-bar-icon.svg`（monitor-buddy），
  `rsvg-convert` 出 18/36/54。Canvas 自绘会变一坨，SF Symbol 不是 logo。录制时另切 record 圆点。

## 发布就绪（详见 docs/RELEASE_READINESS.md）
- 上架只有 iOS 端；Mac 端独立分发。核心风险：
  1) 审核员装不了配套 Mac app → 建议加 iOS 本地"演示模式" + 演示视频；
  2) 营销说"Zoom/OBS 当摄像头"依赖 Camera Extension 用户激活，**尚未真机跑通**，不跑通就得收窄文案。
- 重大功能缺口：Camera Extension 激活验证、虚拟麦克风 HAL 插件、手动 IP 兜底、素材/URL、锁屏提示、录制合轨。
- 明文 TCP（无 TLS）：审核非阻塞，但隐私文档要如实写。
